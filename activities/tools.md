# Empathy-Driven Selling Toolkit

*Achieving Sales Goals with Customer-Centric Selling Techniques · C1088*

## Frameworks used in the activities

| Framework | What it does | Used in |
|---|---|---|
| SPIN Selling (Rackham, 1988) | Situation → Problem → Implication → Need-Payoff: the question sequence that gets the BUYER to state the value. | Activity 1 |
| Gap Questions | Open questions that make the buyer describe the distance between today and the outcome they want. | Activity 1 |
| Why-Why-Why | Repeated 'why' to travel from a surface complaint down to the felt problem. | Activity 1 |
| Cialdini's 7 Principles | Reciprocity, Commitment, Social Proof, Authority, Liking, Scarcity, Unity — used honestly, never to manipulate. | Activities 1, 3 |
| Empathy map (Says/Thinks/Does/Feels) | Captures a buyer's stated words, private thoughts, observable actions and underlying feelings. | Activities 1, 4 |
| Affect labelling (Doug Noll) | Naming the emotion out loud to calm the reaction before arguing the facts. | Activities 1, 4 |
| The buyer's matrix | Maps each stakeholder by power and interest to decide how much time each deserves. | Activities 1, 2 |
| Educate → Demonstrate → Buy-In | The three-part demo sequence: frame the problem, show only the fix, let them describe using it. | Activity 2 |
| Mini closes / trial closes | Low-stakes checks ('does this make sense?') that turn one big yes into several small ones. | Activities 2, 3 |
| Upsell vs cross-sell timing | Upsell = same need, higher tier; cross-sell = adjacent need — both only after the first win lands. | Activity 2 |
| Champion Selling | Identify, equip and rehearse an internal advocate to win the argument you're not in the room for. | Activity 2 |
| Buying-signal taxonomy | Verbal, behavioural and digital cues that tell you the buyer is ready to be asked. | Activity 3 |
| The empathy-driven closing set | Summary, Visual, Backwards, Storytelling, Thermometer and Assumptive closes. | Activity 3 |
| ROI / cost-of-inaction framing | Restate the cost, attach a number, show the offset, then stay quiet. | Activity 3 |
| Mutual action plan | A dated, jointly-owned list of steps from signature to first use. | Activity 3 |
| 17-21 day follow-up cadence | Five or more value-carrying touches spaced 2-3 days apart, never 'just checking in'. | Activity 3 |
| Objection / deflection / rejection | Three responses that sound alike and need opposite handling. | Activity 4 |
| Acknowledge–Clarify–Address–Confirm | The objection framework: validate the feeling before answering the fact. | Activity 4 |
| Answer & Ask + isolation question | Resolve the concern, then re-engage: 'outside of that, is there anything else?' | Activity 4 |
| Feel · Felt · Found | Turns a concern into social proof via a comparable customer's experience. | Activity 4 |
| Five-step emotion regulation | Pause, label, reframe, respond, reassess — composure under pressure. | Activity 4 |
| Sales closure metrics | Conversion rate, cycle length, discount depth and NPS at handoff (K1 / A1). | Activity 4 |

## SPIN quick reference

| Letter | Question type | Example |
|---|---|---|
| **S** | Situation | "Walk me through how a job gets tracked today." |
| **P** | Problem | "Where does that process break down?" |
| **I** | Implication | "What did the missed handover actually cost you?" |
| **N** | Need-Payoff | "What would solving this for good be worth?" |

## Objection, deflection or rejection?

| Response | What it means | What to do |
|---|---|---|
| **Objection** | They want to justify the decision | Give value evidence, then ask a question. |
| **Deflection** | Something else is wrong, unsaid | "If price weren't an issue, what then?" |
| **Rejection** | A genuine no | Accept gracefully, ask what would change it, keep the door open. |
